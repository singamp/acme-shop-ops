# Security policy

This demo app is part of [Guidal](https://guidal.ai). Report vulnerabilities privately, as
described in the [Guidal security policy](https://github.com/guidal-cloud/.github/blob/main/SECURITY.md):
email support@guidal.ai with `SECURITY` at the start of the subject, or use "Report a
vulnerability" on this repository's **Security** tab. Never open a public issue for one.

The worker bug (`qty` instead of `quantity`) was planted on purpose for the demo and is out of
scope.
